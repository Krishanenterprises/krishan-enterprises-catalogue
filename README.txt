# Krishan Enterprises Catalogue

## Upload structure
- `index.html`
- `style.css`
- `script.js`
- `data.js`
- `assets/logo.png`
- `assets/images/`

## Product image naming
For product `KE-DL-001`, upload:
- `KE-DL-001-1.jpg`
- `KE-DL-001-2.jpg`
- `KE-DL-001-3.jpg`

For category cover images:
- `cat-diwali-lights.jpg`
- `cat-home-decor.jpg`
- `cat-table-lamp.jpg`
- `cat-corporate-gifting.jpg`
- `cat-metal-gifting.jpg`
- `cat-decorative-items.jpg`
- `cat-kitchen-products.jpg`
- `cat-personal-care.jpg`
- `cat-gifting-boxes.jpg`
- `cat-decorative-boxes.jpg`

Then edit only `data.js` to add/update products and prices.
